# 📚 Books List

Projeto com foco na manipulação de dados de uma lista de livros, utilizando JavaScript para praticar lógica de programação e funções de array.

## ✨ Demonstração

> Este projeto não possui interface visual. Todas as funcionalidades foram criadas para prática de lógica e são executadas diretamente no ambiente Node.js.

## 💡 Sobre

Neste exercício, foram desenvolvidas diversas funções de manipulação de dados, utilizando métodos de array como `map`, `filter`, `sort`, `find`, entre outros, para interagir com uma lista de objetos representando livros.

Cada função implementa uma lógica específica para filtrar, ordenar ou transformar os dados da lista.

## 🛠️ Habilidades desenvolvidas

- Manipulação de arrays de objetos em JavaScript
- Uso de métodos como `map`, `filter`, `sort` e `find`
- Escrita de funções com responsabilidade única
- Prática de leitura e transformação de dados

## 🧪 Tecnologias utilizadas

- JavaScript ES6+
- Node.js

## 🚀 Como rodar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/JyojiTenguam/exercise-books-list.git
```
2. Acesse a pasta do projeto

```bash
cd exercise-books-list
```
3. Instale as dependências
```bash
npm install
```
